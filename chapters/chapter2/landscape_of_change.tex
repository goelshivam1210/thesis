\section{Two Modes of Adaptation: Assimilation and Accommodation}
\label{sec:assimilation_accommodation}
\label{sec:landscape_of_change}
\label{sec:computational_open_world}

If novelty is defined relative to an agent's knowledge, the next question is how the agent can respond when that knowledge proves inadequate.
The developmental distinction introduced in the preceding section provides a useful vocabulary for describing two broad possibilities.
\citet{piaget1952origins} used assimilation to describe the interpretation of experience through existing cognitive structures and accommodation to describe the adjustment of those structures in response to experience.
Adapting this distinction to artificial agents, we use \emph{assimilation} for changes that can be absorbed within the agent's existing representational and behavioral structure, and \emph{accommodation} for changes that require that structure to be revised or extended, for example by introducing a concept, relation, operator, executor, or abstraction.
The distinction is therefore not about whether an update is small or large, but about whether the agent's current structure is sufficient for the situation it faces.

\Cref{fig:assimilation_accommodation} summarizes the distinction.
Assimilation is possible when the agent already has the terms needed to describe what changed.
The agent may need to adjust a probability, revise a prediction, or improve a policy, but the relevant variables, categories, and actions are already in place.
Accommodation is required when those terms are missing: when a new object category, relation, precondition, action, or dependency must be added before the agent can describe the situation at all.

Work on schema and memory reflects the same asymmetry.
Information that fits an active schema is integrated more efficiently than information that forces the schema to be restructured~\citep{sommer2022assimilation}, and novelty can help or hurt memory depending on how the new information relates to prior knowledge~\citep{quent2021predictive}.

Much of machine learning under change is best understood as assimilation.
Concept drift is the clearest case.
In data-stream learning, drift is usually formalized as a change in the distribution generating examples over a fixed feature space and label space~\citep{widmer1996learning,gama2014survey,lu2019concept}.
The spam-filtering example commonly used in the drift literature makes this assumption concrete: legitimate emails may change in style, and spam messages may adapt to evade a classifier, but the underlying categories and input representation remain fixed~\citep{gama2014survey}.
Adaptation means re-estimating a model whose basic vocabulary is still assumed to fit.

Continual learning, lifelong learning, transfer, and meta-reinforcement learning address related forms of adaptation.
They ask how agents can reuse knowledge, avoid catastrophic forgetting, or adapt quickly to new tasks~\citep{ring1994continual,thrun1995lifelong,parisi2019continual,hadsell2020embracing,kirkpatrick2017overcoming,finn2017maml,yu2020metaworld}.
These are central problems for long-lived agents, but many formulations keep the state space, action space, label space, or task distribution fixed enough that adaptation occurs within a shared representation.
Continual RL reviews make the same point: many settings involve nonstationary MDPs or related task streams, but the changes are often gradual or drawn from a common distribution~\citep{khetarpal2022continual}.
In the language of this chapter, these methods are powerful assimilation mechanisms.
\label{sec:drift_vs_novelty}

Open-world novelty can violate the fixed-vocabulary assumption that makes assimilation possible.
A previously unseen object type may appear; an action may acquire a new precondition; a relation among objects may become task relevant; a familiar operator may require a new executor.
Such changes alter what the agent must be able to express, not merely the distribution over expressions it already has.
Open-world research has consequently examined change not only in objects and observations, but also in agents, actions, relations, interactions, environment rules, goals, and events~\citep{senator2019science,holder2025introduction}.
The same boundary appears in cognitive-systems work as the distinction between out-of-distribution cases and out-of-design-scope cases: the former are unusual but still within the system's assumptions, while the latter violate those assumptions~\citep{wray2025requirements}.
In this dissertation, we study both regimes and emphasize how representational structure determines the boundary between them: which changes can be assimilated within existing competence and which require accommodation through revision or extension.

Accommodation becomes especially important when mismatch blocks action.
Research on creative problem solving has long emphasized that some impasses are not solved by searching longer within the same problem framing; they require the problem to be represented differently.
\citet{duncker1945problem} described this obstacle as functional fixedness, and \citet{boden2004creative} later distinguished exploratory creativity, which searches within a fixed conceptual space, from transformational creativity, which changes the space itself.
Computational creative problem solving brings the same idea into artificial agents: when existing concepts are insufficient, an agent must generate or revise concepts, not only recombine them~\citep{gizzi2022cps}.
In robotics, \citet{gizzi2019creative} operationalize this idea by giving a robot an initially inadequate symbolic knowledge base; when execution fails, the robot explores, segments behavior into new action primitives, and updates its action model.

One nearby research area uses similar language for a different goal.
Open-ended learning studies processes that continue to produce new observations, goals, skills, environments, or other elements over an indefinite horizon~\citep{sigaud2023openended}.
In that setting, producing an expanding repertoire is itself part of the objective.
Open-world autonomy, as used in this dissertation, addresses a different problem: the agent must adapt when its previously adequate knowledge or behavior no longer supports continued task performance, sometimes by accommodating changes that exceed its existing structure.
The two areas share an agent-relative notion of novelty and both depend on abstraction, but they address different problems.
\label{sec:openworld_vs_openended}

The section's central claim is that the boundary between assimilation and accommodation is agent-relative and representation-dependent.
Whether a change can be absorbed or requires representational revision depends on how the agent's knowledge is structured.
An abstraction that captures task-relevant invariances can allow an existing policy or behavior to apply across variation in objects, dynamics, or embodiment, thereby expanding the range of changes that can be assimilated through generalization.
When existing knowledge or behavior is insufficient, an abstraction that decomposes them into explicit, composable components provides interfaces where mismatch can be detected, localized, and repaired through extensions~\cite{sarathy2021spotter}.
By contrast, an agent whose knowledge is encoded as a monolithic mapping from observations to actions has fewer places to attach a new distinction or isolate what must change.
This yields the comparative hypothesis developed throughout the dissertation: structured abstractions make open-world autonomy more tractable in two complementary ways---by enabling assimilation through invariance and generalization, and by making accommodation localized and targeted when structural revision is required.
